# Plana Mini Pet

一个用于 ChatGPT Mini 的 Q 版 Plana（普拉娜）动画精灵图，基于用户提供的《蔚蓝档案》角色参考图制作。

## 内容

- `assets/plana-mini-spritesheet.png`：ChatGPT Mini v2 精灵图，1536×2288，8×11 网格
- `assets/plana-mini-contact-sheet.png`：全部动作接触表
- `assets/plana-mini-direction-qa.png`：16 个环视方向检查表
- `assets/plana-mini-review.gif`：较慢的 review 动作预览

## 动作

包含 idle、左右移动、waving、jumping、failed、waiting、running、review，以及 16 个视线方向。
